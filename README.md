# MediCare – Hospital Appointment & Patient Care System

A responsive, single-page academic prototype for a hospital appointment system.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern web browser.
3. Use the sidebar to explore the dashboard, doctor directory, booking form, appointments, profile, and help pages.

No installation or server is required for this standalone demo.

## Features
- Overview dashboard with appointment counts and next visit
- Searchable doctor directory and specialty filter
- Appointment booking with required-field validation
- Past-date restriction and duplicate doctor/time-slot prevention
- Appointment list, status filter, and cancellation
- Editable patient demo profile
- LocalStorage persistence across refreshes
- Responsive desktop and mobile layout

## Important limitations
- All doctors, fees, and sample appointments are fictional demonstration data.
- Bookings are stored only in the current browser using LocalStorage.
- No real hospital, doctor, patient-record, payment, SMS, email, or cloud service is connected.
- This is not a medical advice tool or a production healthcare system.
